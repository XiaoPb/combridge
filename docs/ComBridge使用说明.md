# ComBridge 使用说明

本文介绍以下功能：

- GH3036 模块的全部 TAB
- 波形图的 CSV 加载
- ComBridge 快捷键

> 文中的“截图占位”可替换为实际界面截图。

## 1. GH3036 模块

### 1.1 使用前准备

1. 将 GH3036 设备通过串口或 BLE 连接到电脑。
2. 在左侧导航栏进入 **GH3036**。
3. 首次使用时，先在 **通道配置** TAB 中配置收发通道。

> **截图占位：GH3036 页面及顶部 5 个 TAB**

GH3036 页面包含 5 个 TAB：**通道配置、数据监控、版本信息、产测、产测配置生成**。

### 1.2 通道配置

此 TAB 用于配置 GH3036 的通信通道、数据自动保存，以及手动执行 CardiffRPC 命令。

#### 配置串口通道

1. 先在 **串口** 页面连接设备。
2. 在“连接类型”中选择 **串口连接**。
3. 选择已连接的串口。
4. 点击 **保存配置**。
5. 出现“通道配置已保存”后即可使用。

串口模式下，发送（TX）和接收（RX）共用同一个串口。

#### 配置 BLE 通道

1. 先在 **BLE** 页面连接设备，并完成服务发现。
2. 在“连接类型”中选择 **蓝牙连接**。
3. 选择已连接的 BLE 设备。
4. 填写 TX UUID 和 RX UUID。
5. 点击 **保存配置**。

通常 TX 为可写特征，RX 为 Notify/Indicate 特征。当前 BLE 设备完成服务发现后，ComBridge 会优先自动匹配常用的 `00000004`（TX）和 `00000003`（RX）特征；自动匹配不正确时可手动修改。

> **截图占位：串口和 BLE 通道配置区域**

#### 保存接收数据为 CSV

1. 打开 **启用 CSV 保存**。
2. 选择或输入输出目录。
3. 点击 **保存 CSV 配置**。

启用后，GH3036 接收到的功能数据会按功能名称分别保存到子目录中。

#### 使用 CardiffRPC 命令

展开 **CardiffRPC命令** 后，可进行以下操作：

| 功能 | 用途 |
| --- | --- |
| 模式选择 | 切换 MCU 在线、MCU 离线或量产测试模式 |
| 版本获取 | 查询指定类型的版本 |
| 发送命令 | 发送 IDLE、RESET、SLEEP、WAKEUP |
| 写/读寄存器 | 按十六进制地址读写寄存器 |
| 配置加载 | 加载 `.config` 或 `.ini` 文件，确认寄存器列表后下载到设备 |
| 功能选择 | 启动或停止 ADT、HR、SPO2、HRV、GNADT 等功能 |
| 产测模式/结果 | 设置产测项目并获取结果 |
| 扩展指令 | 发送自定义命令，格式为“命令,参数1,参数2” |

执行命令前必须先配置发送通道。寄存器和扩展指令属于调试功能，请确认参数正确后再发送。

> **截图占位：CardiffRPC 命令区域**

### 1.3 数据监控

此 TAB 用于查看 GH3036 的实时算法结果和波形。

#### 查看实时指标

页面顶部显示：

- 心率和置信度
- 血氧、R 值和置信度
- HRV 的 RRI 数据和置信度
- 佩戴状态和活体检测状态

未收到对应功能数据时显示 `--`。

#### 查看 IPD/PA 或 Rawdata 波形

1. 先在 **通道配置 → 功能选择** 中启动所需功能。
2. 收到数据后，在波形右上角选择功能。
3. 选择 **IPD** 或 **Rawdata**。
4. 根据设备实际输出设置采样率，横轴时间会按该采样率计算。
5. 点击 **清除数据** 可清空当前波形缓存。

页面下方会同步显示 `ACC_X`、`ACC_Y`、`ACC_Z` 三轴加速度数据。实时图默认显示最近约 6 秒的数据，IPD/Rawdata 最多显示前 4 个通道。

#### 配置金标

- **心率金标**：点击心率卡片的配置按钮，从已经在 BLE 页面连接且支持标准心率服务的设备中选择。系统会自动采集 4 个心率值。
- **血氧金标**：点击血氧卡片的配置按钮，在独立窗口中输入或调整 0～100% 的血氧金标值。

> **截图占位：数据监控指标卡片和波形区域**

### 1.4 版本信息

此 TAB 用于查询设备的固件、协议、驱动、芯片、BLE、Bootloader 及各算法版本。

1. 确认 **通道配置** 中已经保存发送通道。
2. 点击某一行的 **刷新**，查询单个版本。
3. 点击 **刷新全部**，依次查询全部版本。

查询期间按钮会显示加载状态；未配置发送通道时无法刷新。页面底部的“库信息”用于确认 GH3036 库和 RPC 是否已就绪。

> **截图占位：版本信息列表**

### 1.5 产测

此 TAB 用于自动完成芯片初始化、UUID、底噪、PPG 噪声、LPCTR 和 LPLCTR 测试，并按卡控配置判断通过或失败。

#### 第一步：连接设备

推荐使用页面顶部的 **快速连接**：

1. 输入蓝牙名称或 MAC，至少填写一项。
2. 设置扫描时间，范围为 1～60 秒，默认 10 秒。
3. 点击 **一键连接**。

ComBridge 会自动切换到原生 BLE、扫描并连接设备、发现服务、订阅通知，再配置 GH3036 通道。高级设置中的默认 UUID 为：

- TX：`00000004-0000-1000-8000-00805f9b34fb`
- RX：`00000003-0000-1000-8000-00805f9b34fb`

设备使用其他 UUID 时，请在 **高级设置** 中修改。也可以跳过快速连接，直接使用“通道配置”中已配置好的设备。

#### 第二步：选择配置目录

点击 **选择目录**，目录中应包含：

- 一个名称符合 `factory_config_*.yaml` 的卡控配置文件
- 已启用测试项对应的 `.config` 或 `.ini` 文件，文件名分别包含 `base_noise`、`ppg_noise`、`lpctr`、`lplctr`

每类配置只能有一个匹配文件。配置完整后，状态会显示“就绪”，**开始测试** 按钮才可用。

#### 第三步：开始测试

1. 点击 **开始测试**。
2. 查看进度条和当前状态。
3. LPCTR 完成后，程序会提示切换测试环境。
4. 完成环境切换后，点击 **已切换环境，继续测试**。
5. 测试结束后查看总体结果及每个通道的实测值、判断条件和通过/失败状态。

需要中止时点击 **停止测试**。测试结果会追加保存到程序目录下的 `data/factory/factory_<项目名>_<日期>.csv`。

> **截图占位：产测快速连接、配置状态和测试结果**

### 1.6 产测配置生成

此 TAB 用于创建或编辑 `factory_config_*.yaml` 卡控配置。

#### 新建配置

1. 填写项目、版本和描述。
2. 选择失败动作：
   - **停止**：某项失败后停止后续测试。
   - **继续**：记录失败并继续执行后续测试。
3. 分别配置底噪、PPG 噪声、LPCTR、LPLCTR：
   - 是否启用
   - 单位
   - 全局判断条件和阈值
   - 可选的通道专用规则
4. 点击 **生成预览**，确认右侧 YAML 且提示校验通过。
5. 点击 **另存为 YAML**。建议保留默认文件名 `factory_config_<项目名>.yaml`。

项目名称只支持中文、英文、数字、下划线和短横线。

#### 通道规则

通道规则会覆盖对应通道的全局阈值。通道编号用英文逗号分隔，例如 `0,1,2`。可用判断条件包括：小于、小于等于、大于、大于等于、等于、不等于和范围内。

#### 编辑已有配置

1. 点击 **加载 YAML** 并选择 `.yaml` 或 `.yml` 文件。
2. 修改参数后点击 **生成预览**。
3. 点击 **保存 YAML** 覆盖当前文件。

保存前会再次校验；配置不合法时不会写入文件。

> **截图占位：产测配置表单和 YAML 预览**

## 2. 波形图 - CSV 加载

### 2.1 CSV 文件要求

- 文件扩展名为 `.csv`，使用英文逗号分隔。
- 数据单元格应为数字；无法解析的内容会按 `0` 处理。
- 空行会被自动忽略。
- 有表头时，表头中的列名会出现在“选择列”列表中。

示例：

```csv
设备信息,GH3036
CH0,CH1,ACC_X,ACC_Y,ACC_Z
120,135,2,-1,998
125,140,3,0,1001
```

上述文件需要设置“跳过信息区域”为 `1`，并保持“无表头”关闭。

### 2.2 加载并显示 CSV

1. 进入 **波形图 → CSV 加载**。
2. 在加载前设置解析选项：
   - **采样率**：1～10000 Hz，用于把数据点换算成时间。
   - **跳过信息区域**：忽略文件开头的说明行，默认 1 行。
   - **无表头**：文件没有列名时打开，列名会自动生成 `CH0`、`CH1`……
3. 点击 **选择文件** 并选择 CSV。
4. 在每个图表的“选择列”中勾选需要显示的列。
5. 按需要调整图表高度，范围为 150～600 px。
6. 点击 **添加图表** 可增加分组；点击删除按钮可移除多余分组。

文件加载后，名称类似 `CH0`～`CH3`、`Ipd0`～`Ipd3` 的列会自动分到图表 1，`ACC_X/Y/Z` 会自动分到图表 2。每个图表最多显示 4 条曲线。

修改解析选项后，点击 **重新加载** 才会按新设置重新解析当前文件。

> **截图占位：CSV 解析配置和图表分组**

### 2.3 查看和导出波形

- 鼠标悬停在曲线上可查看对应时间点的数值。
- 点击图例可显示或隐藏曲线。
- 拖动图表底部的缩放条可调整查看范围，多个图表会同步缩放。
- 在图表内右键，可将当前图表保存为 PNG 或 SVG。

> **截图占位：CSV 波形、缩放条和右键导出菜单**

### 2.4 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 加载后没有数据 | 检查“跳过信息区域”是否大于或等于文件有效行数 |
| 第一行数据被当成列名 | 文件无表头时打开“无表头”，再点击“重新加载” |
| 时间轴不准确 | 将采样率改为数据实际采样率 |
| 某些值显示为 0 | 检查单元格是否为空或包含非数字内容 |
| 选择了很多列但只显示 4 条 | 每个图表最多显示 4 条，请添加图表后分组显示 |

## 3. 快捷键

| 快捷键 | 生效位置 | 功能 |
| --- | --- | --- |
| `Ctrl + Alt + M` | 全局 | 打开菜单显示配置，可设置侧边栏和顶部 TAB 的显示/隐藏 |
| `Ctrl + Enter` | 串口发送输入框 | 快速发送当前内容 |
| `Ctrl + S` | 协议脚本编辑器 | 保存有改动的脚本 |
| `Ctrl + Z` | 协议脚本编辑器 | 恢复到上一次保存的内容 |
| `Tab` | 协议脚本编辑器 | 插入 4 个空格缩进 |
| `Esc` | 血氧金标独立窗口 | 关闭窗口 |
| `F12` | 开发模式 | 打开开发者工具；正式发布版无效 |
| `Ctrl + Shift + I` | 开发模式 | 打开开发者工具；正式发布版无效 |

快捷键中的 `Ctrl` 在当前版本按 Windows/Linux 键位说明。脚本编辑器的保存与恢复也支持 macOS 的 `Command` 键。
